# 한국어 iOS 테마 기술 디버깅과 버전별 호환성

## A. `.ktheme`가 카카오톡에 나타나지 않음

1. 확장자 실제로 `.ktheme`인지 확인한다(`.ktheme.zip` 아님).
2. `validate_ktheme_archive`가 ZIP 자체 CRC/루트/중복/이미지 경로를 통과하는지 본다.
3. 최상위에 `KakaoTalkTheme.css`, `Images/`가 포함되어 있는지 본다.
4. `ManifestStyle` ID·버전·이름이 정상인지 본다.
5. 기존 버전이 캐시되거나 ID 충돌이 있는지 확인한다.
6. **정적 검사가 성공하더라도** 최신 카카오톡 로더가 수용하는지는 실기기에서만 확인 가능하다.

## B. 채팅방 배경/프로필/탭 아이콘이 표시되지 않음

1. `inspect_ktheme_project` 결과의 `references`를 확인한다.
2. 이미지 베이스명, 실제 `Images/` PNG 파일명, 대소문자, 스케일 일치 여부를 대조한다.
3. 해당 선택자 이름이 출발 샘플과 같은지 확인한다.
4. 배경색과 이미지가 함께 있을 때 이미지 우선 적용 여부를 샘플에서 확인한다.
5. 앱 버전에 따라 해당 화면의 테마 키 적용 범위가 달라질 수 있다.

## C. 말풍선이 늘어나면서 깨짐

1. `MessageCellStyle-Send/Receive`의 이미지 속성 및 그룹 메시지 속성을 함께 살핀다.
2. 늘어나는 방향과 캡 인셋(숫자 뒤 `px` 등)의 의미를 **사용한 샘플**에서 확인한다.
3. 2x/3x 스케일 원본 PNG의 크기 및 꼬리 위치를 비교한다.
4. 짧은 텍스트/긴 텍스트/연속 발화/선택 상태를 각각 실기기에서 테스트한다.
5. 이 MCP는 도형의 미적 재설계를 하지 않고 해당 에셋 파일의 기술 제약만 보고한다.

## D. 리스트 글자만 바꾸려 했는데 다른 버튼 색까지 바뀜

2026-09-15 작성된 커뮤니티 [KEYMAP](https://github.com/han-hyeonmin/kakaotalk-custom-theme/blob/main/KEYMAP.md)은 `MainViewStyle-Primary`의 `-ios-text-color`가 리스트 이름과 일부 통화 버튼·헤더 아이콘을 동시에 바꾸는 사례를 기록했다. 별도 키가 존재한다고 가정하지 않는다. 실제 앱 버전에 맞게 재측정한다.

## E. 공식 2018 가이드와 최신 샘플이 다름

공식 2018 문서: `KakaoTalk.css` 파일명과 `NavigationBarStyle1-V4` 류의 예제를 사용한다. 최근 커뮤니티 샘플: `KakaoTalkTheme.css`와 `HeaderStyle-Main` 류를 사용한다. **두 세대의 파일명/선택자를 섞으면 안 된다.** 사용자에게 앱 버전·샘플 원본을 확인하고 해당 세대만 유지하도록 안내한다.
