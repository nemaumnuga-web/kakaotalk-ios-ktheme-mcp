# 검색 출처, 자료 신뢰도, 버전 문제

이 프로젝트의 `search_ktheme_docs`는 **오프라인 로컬 지식 검색**이다. 외부 인터넷을 실시간 검색하지 않는다. 외부 자료는 URL과 확인 한계를 제공한다. 웹 검색을 할 수 있는 AI 클라이언트는 원본을 다시 조회하되, 사용자 프로젝트의 샘플과 대조한다.

## 1. 공식 카카오 사용자 테마 가이드 (2018년)

https://t1.kakaocdn.net/kakaocorp/Service/Theme/KakaoTalk/iOS_theme_guide_KR_180103.pdf

- 카카오 배포 CDN, 2018-01-03 수정. 역사적 공식 1차 자료.
- Manifest 키, 당시 PNG 이름, 162×162 아이콘, 레거시 구조, ZIP → `.ktheme` 안내를 제공.
- 해당 자료가 최신 iOS 카카오톡 UI의 전체 키 명세라는 주장은 금지.
- 특히 CSS 파일명은 구버전 가이드의 `KakaoTalk.css`와 최근 사용 예의 `KakaoTalkTheme.css`가 다름.

## 2. 최근 커뮤니티 iOS 샘플

https://github.com/han-hyeonmin/kakaotalk-custom-theme

- 현대 CSS 선택자/패키징/설치 사용 예시.
- 개인 프로젝트이며 카카오 공식 보증이 아님.
- 샘플을 복제할 때 저작권·상표·기본 프로필 이미지의 출처 문제를 확인.

## 3. 커뮤니티 실기기 키 측정 (2026-09-15)

https://github.com/han-hyeonmin/kakaotalk-custom-theme/blob/main/KEYMAP.md

- 특정 카카오톡 화면에서 `-ios-text-color` 등과 실제 UI 영역을 대조한 자료.
- 공식 키 전체를 대체하지 않음. 사용자 기기에서 재현 필요.

## 4. 다른 MCP 테마 프로젝트의 기술 참고

https://github.com/jkaae93/kakaotalk_theme_mcp/blob/main/design.md

- 현대 샘플에서의 `@2x/@3x`, CSS 이미지 참조, Messages 셀, 테마 ZIP 구조 예시.
- 본 프로젝트는 디자인 가이드가 아니라 **설계와 정적 엔지니어링 검사**에 한정하여 차별화.

## 5. MCP 구현 참조

https://py.sdk.modelcontextprotocol.io/

- SDK v2: `MCPServer`/`@mcp.tool()`/`@mcp.resource()`/`@mcp.prompt()`/stdio.

## 신뢰도 표현 원칙

| 자료 | 용도 | 결론 수준 |
| --- | --- | --- |
| 공식 2018 | 당시 파일명·규격·키 | 역사적 공식 사실 |
| 현대 샘플 | 구현 가능한 구체 예 | 커뮤니티 구현 근거 |
| 2026 측정 | 일부 실제 키-화면 연결 | 버전 한정 실측 |
| 일반 블로그 | 단서/검색 키워드 | 재확인 필요 |
| MCP 정적 검사 | 파일 계약·오류 | 설치 성공 증빙 아님 |

검색 키워드 예: `KakaoTalkTheme.css MessageCellStyle-Send @3x`, `카카오톡 iOS ktheme ManifestStyle`, `site:github.com "-ios-group-background-image"`, `카카오톡 테마 파일 ZIP 루트 CSS`.
